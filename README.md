Login Page Frontend (HTML & CSS)
This project is a clean and responsive login page built using HTML5 and CSS3, focusing on modern UI design and usability. It includes 
structured form elements, semantic markup, and custom styling to ensure a smooth user experience across different screen sizes. The 
layout is designed with simplicity and accessibility in mind, making it easy to integrate with any backend authentication system. 
This project is ideal for beginners to understand frontend fundamentals and for developers looking for a reusable login UI template.
